1. **Strânge tot ce știm** despre site și produse în fișierele de mai sus, din codul site-ului (prețuri, oferte, texte, studii).
2. **Marchează ce lipsește** în fișele tehnice (dimensiuni, greutate, baterie, certificate etc.), ca să știe Coș exact ce date să trimită.
